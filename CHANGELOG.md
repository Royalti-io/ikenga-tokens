## 0.3.0

### Minor Changes

- Add the Atelier app-kit component layer + no-build distribution.
  - **New opt-in exports:** `@ikenga/tokens/app-kit.css` (the component layer) and the generated JS-string exports `@ikenga/tokens/tokens-css` + `@ikenga/tokens/app-kit-css` for no-build `srcdoc` pkgs (injected as an inline `<style>`; replaces the per-pkg hand-copied CSS-as-JS mirrors that drifted). These retire the per-pkg `aliasCss` shim.
  - **Adopted the Fraunces (display) + JetBrains Mono fonts the shell already loads;** `--font-sans` (Plus Jakarta Sans) is unchanged.
  - **No change** to existing `tokens.css` color, type-_size_, or radius values — `./tokens.css` consumers (the marketing site, the shell) are visually unaffected.
